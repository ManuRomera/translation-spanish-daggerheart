# Historial de cambios

## 0.2.0 — 2026-08-04

### Añadido

- Compatibilidad completa con Daggerheart 1.9.14 y Foundry VTT 13.351.
- Traducción de las 1.779 claves presentes en el archivo inglés del sistema.
- Herramientas para comparar, sincronizar y validar futuras actualizaciones de localización.
- Comprobación automática en GitHub para estructura, sintaxis y variables dinámicas.

### Mejorado

- Terminología unificada para reglas, rasgos, alcances, dominios y recursos.
- Abreviaturas de rasgos y Puntos de golpe adaptadas al español.
- Documentación de instalación, uso, compatibilidad y resolución de problemas.

### Corregido

- Eliminadas cadenas híbridas en español e inglés de la versión anterior.
- Eliminadas claves obsoletas y añadidas las 538 claves incorporadas desde Daggerheart 1.0.0.
- Conservadas todas las variables dinámicas, referencias y fórmulas de dados del archivo original.
- Sustituidos los observadores globales del DOM por ajustes pequeños y específicos.

## 0.1.0 — 2025-08-10

- Primera publicación para Daggerheart 1.0.0 y Foundry VTT 13.
